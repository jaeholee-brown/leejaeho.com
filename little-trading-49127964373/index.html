Everything between an idea and a trade you'd trust.

Small teams end up stitching together notebooks, CSV exports and one-off scripts. Little Trading replaces that with one research environment that's fast by default and hard to fool yourself with.

Fast, parallel backtests

Event-driven and vectorized engines that fan out across elastic cloud compute. Sweep whole parameter grids in parallel instead of leaving a laptop running overnight.

Point-in-time data

Survivorship-bias-free prices, corporate actions and fundamentals as they were known on each date, so a backtest only sees what you could have seen.

Overfitting checks built in

Walk-forward splits, out-of-sample holdouts and deflated Sharpe ratios come with every run. If a result looks too good to be true, you'll hear it from us first.

Research to paper trading

Promote a strategy to paper trading without rewriting it. The same code, cost model and fill assumptions follow it from notebook to market.

Write it once in Python. Test it properly.

Strategies are plain Python functions. Little Trading handles data alignment, execution simulation and evaluation around them.

  1. 01

    Describe the strategy

    Return target weights from a function. Universe, rebalance schedule and constraints are declared, not hand-coded.

  2. 02

    Backtest at scale

    Run on point-in-time data with realistic costs, then walk it forward across folds the strategy never trained on.

  3. 03

    Promote to paper

    When a result holds up out of sample, promote it to paper trading with one call and monitor live against the backtest.

import littletrading as lt

@lt.strategy(universe="us_equities", rebalance="daily")
def mean_reversion(ctx):
    z = ctx.zscore(ctx.close, window=20)
    return -z.clip(-2, 2)  # weights

run = lt.backtest(
    mean_reversion,
    start="2015-01-01",
    costs="realistic",
)
run.walk_forward(folds=5).report()

run.promote("paper")    # same code, on paper
